## 01 — Neon Protocol: Rift

**Type:** 2D browser game · **Status:** In development

**[Explore the source and technical README](https://github.com/Naraya28/neon-protocol-rift)**

### What the project does
A futuristic browser game experiment built with **JavaScript, Phaser 4, and Vite**. The published stage includes a boot sequence, menu navigation, an introductory sector, and a playable character named NOVA.

### Engineering highlights
- Scene-based game structure, including a boot scene, menu, sector intro, and gameplay sector.
- Reusable player entity with keyboard movement, acceleration/deceleration, and camera tracking.
- Game-world environment and HUD implemented in modular source files.
- Development organized into explicitly numbered stages.

### Where it stands
The repository documents **NP-RIFT 03 — NOVA PLAYER FOUNDATION**. Combat, save data, and several menu systems are not implemented at this stage. See the repository README for exact controls and local run instructions.

**Main technologies:** JavaScript · Phaser · Vite · HTML/CSS

## 02 — Sistem Informasi Masjid Al-Firdaus

**Type:** Web information and management system · **Status:** Source-code project

**[Explore the source and setup notes](https://github.com/Naraya28/sistem-informasi-masjid)**

### What the project does
A PHP-based website combining public information about the mosque with administrative pages for articles, organizational information, finance, reports, and messages.

### Engineering highlights
- Public pages for news, mosque information, and contact.
- Separate dashboard areas for **admin, treasurer, and staff**.
- Financial views covering income, expenses, and balance summaries.
- Shared PHP components and SQL migration scripts for evolving application features.

### Where it stands
The source code is public, but a hosted demo and a complete initial database import have not been verified. The README explains the project structure and what is needed to start setting up a local PHP/MySQL environment.

**Main technologies:** PHP · MySQL · HTML/CSS · JavaScript
